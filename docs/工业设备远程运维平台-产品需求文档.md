# 工业设备远程运维平台 — 产品需求文档（PRD）

**版本：** V1.0  
**产品形态：** Web 管理平台 + RustDesk 被控端  
**开发原则：** 基于 RustDesk 二次开发，优先复用现有能力，尽可能少改动上游代码。

## 1. 产品目标

开发一个类似向日葵的远程设备管理平台。

管理员通过浏览器登录平台，可以查看已经登记的工业设备，并在无需被控端逐次确认的情况下查看设备屏幕。

支持设备：

- Windows 工业电脑
- Android 工业平板及工业终端

核心目标：

- 浏览器统一管理设备。
- 设备自动上线和离线监测。
- 浏览器直接查看设备远程画面。
- 无需每次连接都要求现场人员确认。
- 支持自建 RustDesk 服务端。
- 支持设备分组及简单用户权限。

设备必须事先完成平台登记及授权。远程查看采用只读模式，不提供远程输入或生产机器操作。

## 2. 用户角色

第一版只设置两个角色：

### 管理员

- 登录平台。
- 添加、管理设备。
- 查看所有设备。
- 查看设备远程画面。
- 管理普通用户。
- 查看会话记录。

### 普通用户

- 登录平台。
- 查看授权范围内的设备。
- 查看设备在线状态。
- 打开设备远程画面。
- 查看自己的会话记录。

暂不开发复杂的审批、组织层级和多级角色体系。

## 3. 核心功能需求

### 3.1 用户登录

- 用户名和密码登录。
- 用户身份认证。
- 登录状态管理。
- 基础角色权限控制。
- 密码安全存储。

### 3.2 设备管理

设备列表展示：

| 字段 | 说明 |
|---|---|
| 设备编号 | 平台唯一编号 |
| 设备名称 | 自定义设备名称 |
| 设备类型 | Windows / Android |
| RustDesk ID | RustDesk 设备标识 |
| 在线状态 | 在线 / 离线 |
| Agent 版本 | 客户端版本 |
| 最后在线时间 | 最后心跳时间 |
| 所属分组 | 设备分组 |

操作：

- 添加设备。
- 编辑设备信息。
- 删除设备。
- 禁用设备。
- 查看设备详情。
- 查看设备屏幕。

### 3.3 设备接入

- Windows 设备部署 RustDesk 客户端。
- Android 设备部署 RustDesk 客户端。
- 统一配置自建 RustDesk 服务端。
- 设备完成首次登记和授权。
- 平台保存设备与 RustDesk ID 的对应关系。
- Agent 运行后定期报告设备状态。
- 服务端更新设备在线状态。

设备登记完成后，授权范围内的远程查看不需要每次在设备端进行人工确认。

### 3.4 在线状态

设备状态分为：

- ONLINE：在线。
- OFFLINE：离线。
- DISABLED：已禁用。

通过心跳更新时间判断设备在线情况。

### 3.5 浏览器远程查看

这是系统的核心功能。

要求：

- 从设备列表点击远程查看。
- 在浏览器新页面或弹窗打开远程画面。
- 不需要安装 Windows 或 macOS 控制端。
- 支持 Windows 和 Android 设备。
- 支持画面缩放。
- 支持全屏。
- 支持连接状态展示。
- 支持主动断开。
- 网络异常时自动结束会话。

本版本只提供远程屏幕查看，不支持远程鼠标键盘输入、命令执行或生产设备操作。

### 3.6 会话记录

记录：

- 用户 ID。
- 设备 ID。
- 会话开始时间。
- 会话结束时间。
- 会话持续时间。
- 会话状态。
- 连接异常原因。

### 3.7 设备分组

支持：

- 创建分组。
- 修改分组。
- 删除分组。
- 将设备加入分组。
- 按分组查看设备。

## 4. 页面规划

第一版只开发以下页面：

| 页面 | 主要内容 |
|---|---|
| 登录页 | 用户登录 |
| 首页 | 设备总数、在线数、离线数 |
| 设备管理 | 设备列表及搜索 |
| 设备详情 | 设备信息及状态 |
| 远程查看 | 浏览器远程画面 |
| 用户管理 | 用户及角色 |
| 会话记录 | 历史查看记录 |

## 5. 第一版不开发的功能

- 文件传输。
- 远程终端。
- 远程命令执行。
- PLC 写入或控制。
- 生产设备启停和运动控制。
- 工艺参数修改。
- 复杂审批流。
- 多级组织架构。
- AI 自动诊断。
- 视频录像。
- 设备批量运维。

## 6. MVP 验收标准

1. 管理员可以成功登录。
2. 可以登记 Windows 和 Android 设备。
3. 设备上线后平台可以显示在线。
4. 设备离线后平台可以更新状态。
5. 浏览器可以查看 Windows 设备屏幕。
6. 浏览器可以查看 Android 设备屏幕。
7. 已登记授权设备的只读查看不需要逐次现场确认。
8. 未授权用户无法查看设备。
9. 可以主动结束远程查看会话。
10. 能查看历史会话记录。

## 7. 产品开发原则

- 优先复用 RustDesk。
- 不从零实现屏幕采集和视频传输。
- 不随意修改 RustDesk 核心通信协议。
- 业务平台尽量保持简单。
- 优先完成 Windows 和 Android 浏览器查看能力。
- 先验证浏览器远程画面，再完善管理后台。
